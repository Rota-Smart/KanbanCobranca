Rota Smart — Kanban de Cobrança
================================

COMO INSTALAR (outro computador):
1. Copie rota-smart.exe para qualquer pasta e execute com dois cliques — não
   precisa instalar nada (apenas WebView2, já incluso no Windows 10/11).
2. Dados ficam em %APPDATA%\RotaSmart (banco, backups diários, logs).
3. O exe é maior desde a v1.3.0 (~79 MB): traz o modelo de voz em português
   embutido (veja abaixo).
4. MODO PORTÁTIL (novo na v1.4.0): se a pasta "RotaSmart-dados" estiver ao
   lado do exe, TODO o dados local (banco com configurações, colunas,
   parâmetros) é lido dela — o zip já vem com a pasta, então o app abre
   já configurado. Para zera, basta apagar a pasta.
5. Os botões de minimizar/maximizar/tela cheia/fechar que ficavam dentro do
   app foram removidos na v1.4.1 — use os da própria janela do Windows.

PRIMEIROS PASSOS:
1. ⚙ Configurações → Sessão do 360: clique em "Conectar" — abre o site numa
   guia do Chrome; faça login lá UMA vez e o app captura e salva o cookie
   (nas próximas é automático). Alternativa manual: cole o cookie
   (F12 → Application → Cookies).
2. ⚙ Configurações → Groq: cole sua chave gratuita (console.groq.com); modelo
   sugerido openai/gpt-oss-120b (alternativa rápida: openai/gpt-oss-20b).
3. 💬 Assistente: peça ações em português ("adicione o cliente 24755 em Cobrança",
   "abra o ticket 67220", "melhore o texto do ticket 67220 adicionando X e envie",
   "mude o status do ticket 67220 para Concluído").
4. Arraste um card para a coluna "Cobrança" para gerar a proposta automática.

-----------------------------------------------
CONEXÃO COM O 360 (novo na v1.4.0)
-----------------------------------------------
O Chrome novo bloqueia a leitura do cookie pelo app (criptografia App-Bound).
Agora a conexão usa uma guia própria: "Conectar" abre o 360, você loga uma vez,
o app captura o cookie da guia e salva — e reutiliza nas próximas aberturas.

-----------------------------------------------
FALE COM O ASSISTENTE (novo na v1.3.0)
-----------------------------------------------
No chat do assistente há um botão 🎤: clique, fale e a fala vira texto na hora —
transcrição 100% local (Vosk, modelo já embutido no app, sem internet e sem
configurar nada). O que aparece em cinza é a transcrição parcial enquanto você
fala; a frase final entra no campo de mensagem. Clique de novo para parar.

O assistente também atua em tickets do helpdesk do 360: ler o detalhe com as
interações, abrir o ticket na aba do Chrome que já está no 360, escrever a
resposta (diga "melhore o texto e envie") e alterar o status.

ATUALIZAÇÕES:
⚙ Configurações → Atualizações → "Verificar atualizações" — o app baixa e se
reinicia sozinho a partir da branch release de github.com/luisboneta/KanbanCobranca
(versao.txt + rota-smart.exe). Para publicar versão nova: bump em
internal/atualizacao/atualizacao.go (VersaoApp), wails build, e suba o exe + o
versao.txt novos nessa branch.

-----------------------------------------------
SINCRONIZAR ENTRE PCs
-----------------------------------------------
Os dados agora podem ficar iguais em vários PCs via GitHub:

1. Crie um token em github.com/settings/tokens (clássico, escopo "repo").
2. No app, abra Configurações → Sincronização (GitHub), cole o token e salve.
3. Use o botão "⟳ Sincronizar" no topo do app:
   - Envia suas mudanças para o repositório, ou
   - Baixa os dados mais recentes (aplica ao reiniciar o app).

Se os dois PCs mudarem ao mesmo tempo, o app pergunta qual lado vence.
Repositório: github.com/luisboneta/banco-de-dados (privado).
